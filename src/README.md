This is the command line interface, prime number tool.

A tool that would allow mathematicians that desire an easier way to work with prime numbers. I based this tool on a number of different things that I would like to have with what I'm personally doing, but I also wanted to better understand rust and some algorithms behind prime numbers. This is my first github published project and I couldn't be more excited to learn more and gain more experience with everything.

There are currently 6 proposed tools that I want to add for V1.0:

Prime number validation (100% working, 50% efficiency) 

Prime number generation (In progress)

Prime number factorization

Prime subtype validation

Encryption generator

Prime sum puzzle.

I will keep the README updated with what changes I have, and you can also look at the commit log to check where I'm at with everything. Please feel free to contribute or reach out by emailing me at moose3036@gmail.com
