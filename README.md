This is the command line interface, prime number tool. 

A tool that would allow mathematicians that desire an easier way to work with prime numbers. I based this tool on a number of different things that I would like to have with what I'm personally doing, but I also wanted to better understand rust and some algorithms behind prime numbers.
This is my first github published project and I couldn't be more excited to learn more and gain more experience with everything.

There are currently 6 proposed tools that I want to add for V1.0
1. Prime number validation (100% working, 50% efficiency)
2. Prime number generation (In progress)
3. Prime number factorization
4. Prime subtype validation
5. Encryption generator
6. Prime sum puzzle
